# Known Issues

No code or content defect is currently accepted for the final release candidate. Platform certification, signing, store submission, media capture, and real-device test gaps are release tasks, not accepted product defects.

An issue may be listed here only when it is low severity, understood, reproducible, has negligible impact or a safe workaround, and cannot cause data loss, a mission block, platform rejection, or a material accessibility failure. Record the issue link, affected builds/platforms, reproduction, workaround, owner, and explicit ship approval.

P0 blockers and P1 critical defects must be zero. A P2 requires explicit sign-off; P3/P4 items may be deferred to the post-launch backlog.
