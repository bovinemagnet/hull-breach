# Hull Breach 1.0

Hull Breach is a top-down science-fiction survival shooter where every gunshot can attract something worse.

- Fight through an eight-mission single-player campaign.
- Use keyboard/mouse, controller, or landscape touch controls.
- Manage five weapons against seven distinct alien enemy types.
- Exploit sound, dynamic power and lighting, environmental hazards, and access systems.
- Choose Explorer, Standard, or Survivor difficulty.
- Resume from persistent campaign saves and recoverable checkpoints.

Version 1.0 will be published only after the release candidate completes platform, signing, store, full-campaign, save-upgrade, accessibility, and input approval.
