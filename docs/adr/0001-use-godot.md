# ADR-0001: Use Godot

## Status

Accepted

## Context

Hull Breach needs a lightweight, cross-platform engine with strong 2D tooling and practical desktop and mobile support.

## Decision

Use Godot 4.x, initially pinned to Godot 4.7.2 Standard.

## Consequences

The project gains an open-source engine, an integrated scene editor, and no engine royalty. Engine-specific scenes and GDScript become core project formats, and upgrades require deliberate compatibility testing.
